创建版本库
mkdir 目录名
cd 目录名   (切换，进入别的目录)
pwd(输出当前所在目录位置)
git it

把文件添加到版本库
git add文件名      添加文件到暂存区
git commit --m "add文件名“    一次性提交暂存区的所有修改

git status 显示仓库当前的状态
git diff 文件名   查看修改情况

版本回退
git log 显示提交日志
1.退回上一个版本    git reset --hard HEAD^     上上个版本HEAD^^       往上一百个版本  HEAD~100
--hard  退回上个版本已提交状态    --soft  退回上个版本未提交状态    --mixed退回上各个版本已添加但未提交状态
2.回到未来某个版本   git reset --hard 版本号
git reflog   记录每一次命令，确定未来版本的版本号

git 管理的是修改不是文件   不用git add添加到缓存区，那就不会加入到commit中

撤销修改
一.删除内容在工作区
git checkout -- 文件名   把文件在工作区的修改全部撤销
1.自修改后没有放入暂存区     改回和版本库一样的状态
2.已经添加到暂存区，又做了修改     改回到添加到暂存区的状态
二.铲除内容在暂存区
git reset HEAD 文件名      把暂存区的修改退回到工作区
再用 git checkout -- 文件名
三.删除内容在版本库
git reset --hard HEAD^
